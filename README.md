Operating systems projects from CS416 at Rutgers University.

## Projects

- [Project 2 — User-level threads and scheduling](project2/). A C thread library with timer preemption, mutexes, joins, and PSJF, MLFQ, and CFS schedulers.

Originally developed by Aarya Dalal and Aarya Kansara. This repository includes subsequent bug fixes and regression tests.
